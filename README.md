It uses a simple example to tell you how to use the API function to obtain the results from other project-program.
For example, you write a project by python in your own computer, but Peter want to obtain this project's results.
So, you need to make a interface that could be used by Peter via POSTMAN software.

Main_test.py is the original code.
Main_API_interface.py is a simple API for Main_test.py, but can only be used in local.
Main_API_macs_wifis.py is an improved version of Main_API_interface.py, that can be used by other compuers connecting different wifis.
